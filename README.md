# RestDesk

Open-source desktop companion for healthy work routines, inspired by DeskRest.

## Overview

RestDesk helps you stay healthy and productive during long desk sessions by promoting regular breaks, physical movement, and eye strain reduction.

## Core Features (Planned)

- **Break Reminders**: Customizable intervals for short pauses and longer rest sessions.
- **20-20-20 Rule**: Prompts to look at an object 20 feet away for 20 seconds every 20 minutes to reduce eye fatigue.
- **Posture Checks**: Gentle reminders to adjust seating, stretch, and maintain ergonomic posture.
- **Non-Intrusive**: Runs quietly in the system menu bar or tray with discrete notifications.

## Project Status

RestDesk is currently in early planning and design. Architecture specifications and initial prototypes are in progress.
